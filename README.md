INKRAIL — Draw the Rails, Run the Trains Home. A daytime cartography-map train game: drag from a waiting train to draw its rail in ink, deliver each train to the station of its colour, survive 10 waves, and clear the path for the Midnight Express on waves 5 and 10. 100% offline, no network requests, no external fonts or libraries — just canvas, procedural art and synthesised WebAudio sound.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome. Or serve `game/` with any static file server and open `game/index.html`.
